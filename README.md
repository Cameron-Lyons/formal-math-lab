# Formal Math Lab

A collection of Lean 4 proofs, finite-case solutions, obstructions, and computational checks in combinatorics, Ramsey theory, finite algebra (the Equational Theories Project), number theory, Erdős problems, OEIS conjectures, and discrete geometry.

Each Lean project is a standalone Lake package. Its README states the math problem, source references (arXiv, DOI, OEIS, Erdős problem, or ETP equation), Lean theorem names, build commands, and trust boundaries. Literature checks are logged in [PRIOR_ART.md](PRIOR_ART.md) (updated 27 November 2026). When a note says no earlier proof was found, that covers only the sources checked and does not claim absolute priority.

## Computational proofs

Every 27-element set of nonzero residues modulo 41 admits an ordering with distinct nonempty partial sums. Scaling reduces the proof to checking sets whose total is 0 or 1. [Erdős #475 proof and verifiers](erdos-475-mod41-size27/)

For Erdős problem #272, the maximum number of distinct subsets with nonempty arithmetic-progression intersections is **82 on thirteen points** and **95 on fourteen points**. Lean checks the constructions. A rank bound and a C++ search give the thirteen-point upper bound. A direct clique search gives the fourteen-point upper bound. The fourteen-point proof also establishes the conjectured formula at every $N$ for families with at most $\lfloor(N-1)/4\rfloor$ members containing a seven-term progression. [Thirteen-point proof](erdos-272-thirteen/) · [Fourteen-point proof and general bound](erdos-272-fourteen/)

Covering every trio among 14 people requires exactly 25 six-person groups. Two independent C++20 verifiers rule out 24 groups, and an explicit 25-group construction covers all 364 trios. [Proof and group list](research/covering-14-6-3/)

The longest snake on a $13\times n$ grid gains 48 squares every six columns for $n\ge7$. Two C++17 verifiers check the formula for every width, and a Python constructor gives a longest snake for any requested width. [Height-13 snakes](research/height-13-snakes/)

On a $14\times n$ grid, six more columns add exactly 52 squares to the longest snake for every $n\ge18$. Lean proves that the stated length is attained and bounds every induced grid path. Its finite checks use the native evaluator. Two independent C++17 verifiers and a Python constructor are also available. [Lean theorem](research/height-14-snakes/lean/Height14.lean) · [Formula and reproduction commands](research/height-14-snakes/)

On a $15\times n$ grid the longest snake has $\lfloor(28n+10)/3\rfloor$ cells for every positive width with eleven explicit exceptions, the last at $n=25$. Two exhaustive C++ computations check the same six-column shift in every boundary score. [Height-15 formula and proof](research/height-15-snakes/)
