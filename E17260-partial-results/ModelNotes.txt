E17260 finite-model search notes
================================
Law: x = (y*x) * (z*(x*(z*z))).

Search17260.py uses Z3 finite enumeration sorts, exact total binary table,
and all n^3 instances. Each SAT table would be rechecked by direct evaluation.
It returned UNSAT at orders 2,3,4,5,6 (known bounds, independently reproduced).
Searches above order 10 are resource-limited: UNKNOWN is not an exclusion.

Search17260_sat.py uses a compact, equisatisfiable propositional encoding.
F[a,b,c] says a*b=c, with exactly one c for each (a,b).
C[x,a] contains all y*x.
U[x,z,a] contains the intermediate x*(z*z).
T[x,b] contains all z*(x*(z*z)).
Clauses:
 F[y,x,a] => C[x,a]
 F[z,z,d] & F[x,d,a] => U[x,z,a]
 U[x,z,a] & F[z,a,b] => T[x,b]
 C[x,a] & T[x,b] => F[a,b,x].
Every genuine model extends these predicates using their actual images.
Conversely the implications propagate every term value and enforce the law.
The symmetry restriction f(0,j)<=j+1 can be obtained by relabeling elements
in first-row discovery order. Search results are external evidence only;
no UNSAT result from these scripts is currently a Lean theorem.

The SAT solver produced UNKNOWN at every order 11 through 20 under a
50,000-conflict budget per order. The SMT solver has also returned UNKNOWN
in its completed above-10 runs. See the JSON-line logs for exact budgets/results.

Structural observations (also independently found by other agents):
Let C_x={y*x:y in G}, T_x={z*(x*(z*z)):z in G}.
C_x*T_x={x}. Therefore rectangles C_x x T_x are pairwise disjoint,
and sum_x |C_x||T_x|<=|G|^2.
For any square q=z*z, x*q=x'*q and C_x intersect C_x' implies x=x'.
Hence within each fiber of R_q, the columns C_x are pairwise disjoint.
Thus sum_x |C_x| <= |G| |C_q|.

The directed graph b -> a*b is strongly connected: from z to any x there
is the path z -> z*z -> x*(z*z) -> z*(x*(z*z)) -> x. The last multiplier
is y*x, with y arbitrary. This holds without finiteness.

For every row z, x -> (z*x,z*(x*(z*z))) is injective into S_z^2,
where S_z={z*t:t in G}. Consequently |G| <= |S_z|^2 for finite G.
If c=a*b, then b=c*(z*(b*(z*z))) belongs to row-image S_c for every z.

No affine model over any nonzero abelian group (not just vector spaces):
Writing a*b=Aa+Bb+c for additive endomorphisms gives A^2=0,
AB+B^2 A=I, BA+B^3 A+B^4=0. First show B is injective: if Bv=0,
the second equation gives v=B^2 Av. Then B^3 Av=Bv=0, so the third
gives BAv=0 and hence v=0. The third equation applied to Av gives
B^4 Av=0; injectivity gives Av=0. Finally the second gives v=0.
The structure agent formalized this argument in Affine17260.lean.

Final bounded search results:
- Unrestricted SMT: UNSAT at 2-6. UNKNOWN at 11-13 (120 sec each).
- Initial SAT encoding: UNKNOWN at 11-20 (50,000 conflicts each).
- Deeper SAT: order 11 UNKNOWN after 2,000,000 conflicts.
- No-idempotent SAT: orders 11,12 UNKNOWN after 1,000,000 conflicts each.
- No-idempotent/no-2-cycle SAT with fixed square 3-cycle: orders 11,12
  UNKNOWN after 1,000,000 conflicts each.
- Remaining active runs were interrupted and logged as such. No search
  process was left running. No finite model was found. No new size bound
  above the project's known bound of 10 was established.

The final Search17260_sat.py has exact column predicates and onehot
intermediate terms. Older logs predate these propagation improvements.
It defaults to no special cycle pruning, a single size 11, and 50,000
conflicts. --prune-cycles enables the necessary no-1/no-2-cycle conditions;
--cycle K restricts to tables with a square cycle of length K. Such a
restricted UNSAT result would NOT exclude every model of that order.

Reproduction:
 python3 -m venv .search-venv
 .search-venv/bin/pip install -r requirements-search.txt
 .search-venv/bin/python Search17260_sat.py --min 11 --max 11 --conflicts 50000
 .search-venv/bin/python Search17260_sat.py --min 11 --max 11 --conflicts 1000000 --prune-cycles --cycle 3
 .search-venv/bin/python Search17260.py --min 11 --max 11 --timeout 120

Final script syntax was checked, and the unpruned final SAT encoding was
smoke-tested at orders 2-5, all UNSAT (search17260-sat-final-smoke.log).

Failed weakening avenue:
The weakening for every x,z there exists u with (y*x)*(z*u)=x for every y
has all right-zero magmas as models: set a*b=b and u=x.
Even requiring u=a*(z*z) for some a has an idempotent-free order-4 model:
 3 0 3 1
 3 0 3 0
 3 0 3 0
 2 0 3 0
This table DOES NOT satisfy E17260. It refutes only that proof strategy.
With additional absence of square 2-cycles, bounded SMT found UNSAT at
3-5 and UNKNOWN at 6-10; this remains purely exploratory evidence.
