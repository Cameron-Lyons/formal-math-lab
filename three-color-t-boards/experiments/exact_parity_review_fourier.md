# Independent review of the Fourier ideal

**No mathematical defect found.** The ordinary polynomial quotient dimension
over `F2` equals the number of full labeled valid ternary boards. This is an
exact reformulation whose numerical dimension has not yet been evaluated.

Let `K=F2`, `L=F4`, and let `I` be the original exported ideal generated by all
100 domain polynomials `z_i^3+1` and the 40 selected Fourier moments.

1. **Domain and multiplicities.** In characteristic 2, the derivative of
   `X^3+1` is `X^2`, which is coprime to `X^3+1`. Its three distinct roots in
   `L` are `1, w, w^2`. After extending scalars to `L`, the domain quotient
   splits as a product of one copy of `L` for every labeled coloring. An ideal
   in a finite product of fields simply drops some factors and keeps the rest,
   so `L[z]/I_L` is isomorphic to `L^N` with no nilpotent multiplicities, where
   `N` is the number of valid labeled colorings. This uses the product-of-fields
   structure directly, rather than the false general claim that every quotient
   of a reduced ring is reduced. For the related finite étale characterization,
   see [Stacks, Lemma 10.143.4](https://stacks.math.columbia.edu/tag/00U3).

2. **Fourier completeness.** On `{1, w, w^2}`, the three character functions
   `1, z, z^2` form an invertible Vandermonde matrix, so their fourfold tensor
   product is an invertible transform on all 81 patterns. The uniform parity
   vector has zeroth moment 1 and every nonzero moment 0. The zeroth moment is
   1 automatically because there are 81 placements. All 80 nonzero moments
   vanish if and only if every pattern count is odd, and 81 nonnegative odd
   integers summing to 81 must all equal 1.

3. **Frobenius pairing.** Modulo the domain equations, `P_e^2 = P_(2e mod 3)`.
   Doubling pairs up the 80 nonzero exponent vectors with no fixed points, and
   picking the vector whose first nonzero entry is 1 selects one from each pair.
   Each dropped equation already belongs to the ideal generated by its kept
   partner and the domains, so no extra radical closure step is needed.

4. **Four-variable elimination.** The four linear moments have rank 4. The
   exported formulas for cells `0, 81, 90, 99` solve them uniquely in terms of
   the other 96 cells, giving a ring isomorphism rather than a many-to-one
   projection. The reduced export keeps all 96 free-variable domains, all four
   substituted pivot domains `L_p^3+1`, and the 36 substituted nonlinear
   moments. Reducing exponents modulo 3 is valid modulo those domains. No
   Boolean relation `z^2=z` is applied; exponent 2 is preserved.

5. **Scalar extension and the count.** Tensoring a finite-dimensional
   `K`-vector space with `L` keeps its dimension unchanged, so
   `dim_K(K[z]/I) = dim_L(L[z]/I_L) = N`. There is no division by 2 for
   Frobenius or by 12 for board symmetries, since the exports impose no color
   or reflection normalization. Counting `F2`-rational points instead would be
   wrong: the only `F2`-rational domain point is the invalid all-1 board. The
   quotient dimension includes the degrees of the nontrivial residue fields and
   counts all of their `F4` embeddings.

## Independent artifact checks

`exact_parity_review_fourier.py` imports neither the Fourier generator nor its
arithmetic helpers. It implements `F4` multiplication directly by polynomial
arithmetic, rebuilds the board windows from geometry, and multiplies ordinary
polynomials modulo `z_i^3+1`.

The script checked:

- All 100 original domains, all 40 original moment polynomials, and all 40
  Frobenius pairs against the JSON exports.
- Rank 4 of the linear system and the partition into free and pivot variables.
- All **40 reduced polynomials symbolically**, including the four pivot
  domains, via general polynomial substitution and multiplication.
- Every equation on **60 valid board images** (the 5 published seeds under all
  12 color and reflection symmetries).
- The 73-pattern uniform-triple counterexample: its pivots reconstruct
  correctly, and it fails **8 original moments and 8 reduced equations**.

Note one schema detail: the reduced JSON lists the 96 free-domain equations in
a metadata string instead of inside `remaining_equations`. Any consumer must
add them explicitly, or it will build the wrong ideal. The original Singular
file uses an ordinary characteristic-two polynomial ring as intended.

No counting or standard-basis run was performed, and none of the math agent's
files were changed. Reviewed input hashes and check results are in
`exact_parity_review_fourier_results.json`. Reproduce with:

```sh
python experiments/exact_parity_review_fourier.py
```
