# Exact translation factorization of the natural F₃ ideal

The unrestricted native-field quotient factors as

```
F₃[a]/(a³−a) ⊗_(F₃) A₀,
```

where `A₀` is the valid-board quotient with normalized apex color zero. The
new frozen inputs retain the independent offset variable `a`, so their
quotient dimension is the **full labeled count N**, with multiplier and
divisor one. They have 95 coupled variables and one independent variable.
The unrestricted quotient dimension is not computed here. A subsequent
[bounded fixed-prefix validation](exact_f3_translation_six.md) completed and
reproduced the known six solutions, retaining all 96 variables and fixing the
offset through the original apex color.

## The moment ideal separates from the offset

Set `a=z_apex` and `d_v=z_v−a`, so `d_apex=0`. This is an invertible linear
change from the 100 original colors to `a` and the 99 other normalized colors.
For exponent vectors `e∈{0,1,2}⁴`, binomial expansion gives

```
M_e(a+d) = Σ_(f≤e) binom(e,f) a^(|e−f|) M_f(d).
```

The target vector `t_e` is one only at the maximal vector `2222`, and zero
elsewhere. It is fixed by this triangular transformation: a term with
`f=2222` can occur only when `e=2222`, with coefficient one. Hence

```
M_e(a+d)−t_e
 = Σ_(f≤e) binom(e,f) a^(|e−f|) (M_f(d)−t_f).
```

The constant moment is identically `81=0`. On the other 80 moments the matrix
is triangular with diagonal one; its inverse is translation by `−a`.
Therefore the ideals generated by translated and normalized moment equations
are equal over the polynomial ring, before evaluation at field points.
Individual moments need not be invariant; their full generating ideal is.

The domain equations also separate:

```
(a+d_v)³−(a+d_v) = (a³−a)+(d_v³−d_v).
```

The apex domain supplies `a³−a`; subtracting it from the other domains
supplies each normalized field equation. The four unary role equations are
independent of `a` because each role has 81 cells and `81a=0` in F₃.

After the invertible prefix change and unary elimination on the normalized
colors, the coupled ideal is exactly the normalized moment ideal in 95 free
prefix variables with their individual field equations. Thus the displayed
tensor decomposition is an isomorphism of algebras. Since the independent
factor has dimension three, `N=3·dim(A₀)`. The exported input contains this
factor explicitly; its count must **not** be multiplied by three again.

## Exact coordinates and the independent variable

Use the same Gray cell order and signed normalized prefixes as in
[the native model](exact_f3_math.md):

```
u_j = Σ_(k≤j) d_order[k],
d_order[j] = u_j−u_(j−1).
```

The original apex cell occupies position eight in this order, so `d_apex=0`
is precisely `u8=u7`. Start from the native model's 96 free prefix indices,
remove index eight, and retain the other 95 in ascending order. Its existing
unary eliminations become

```
u80 = 0,
u16 = u97,
u81 = −u7+u72+u98,
u99 = −u7+u9−u65+u82.
```

Input variables `x1,…,x95` are those normalized free prefixes. Variable `x96`
is `a`. Original colors reconstruct as `a+d_v`, and original prefix `j`
reconstructs as `u_j+(j+1)a`. In particular the original apex is `a`, not
fixed zero. The generator checks these inverse maps symbolically.

Every field domain is retained, including the independent
`x96³−x96`. All moment and optional elementary generators use only the first
95 variables. This is a field factor with three distinct values, not an
extension-field generator or a repeated-root multiplicity.

## Native cubic consequences separate as well

For any list of 81 colors, elementary translation gives in F₃

```
e3(z+a) = e3(z)+a*e2(z)+a²*e1(z).
```

The coefficients follow from `binomial(81,3)=0`, `binomial(80,2)=1`, and
`79=1` modulo three. The native unary equations already force `e1=e2=0`.
Thus the four role `e3` constraints, and their equivalent boundary-difference
basis, are invariant modulo the base ideal. Their normalized augmentation is
exported separately and preserves the same tensor factorization.

## Symbolic comparison

| Quantity | Native prefix model | Translation-separated model |
|---|---:|---:|
| Coupled variables | 96 | 95 |
| Independent offset variables | 0 | 1 |
| Field-domain terms | 192 | 192 |
| Retained moment terms | 96050 | 95490 |
| Four optional `e3` terms | 574 | 566 |
| Degree-at-most-three moment span rank | 26 | 26 |
| That rank with `e3` added | 30 | 30 |

Both base inputs have 172 generators; their optional cubic augmentations have
176. The normalized cubic support sizes are `156,174,86,150`. Moment degrees
remain two through eight. The symbolic-size reduction is modest; no basis
runtime advantage is asserted.

moments directly on the original colors `a+d` and verifies every binomial
translation identity, including the maximal nonzero target. The field-domain
and role-`e3` shift identities are checked as ordinary polynomial identities.
Twelve arbitrary normalized assignments are checked at all three offsets,
and 161 existing valid boards round-trip through the complete coordinates.

unevaluated.
