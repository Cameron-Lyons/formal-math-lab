This review establishes equivalence of the reduced models to the previously
audited four branches; it does not evaluate their unrestricted dimensions.

For each branch, the checker independently solves its k+1 affine equations
by Gaussian elimination using the selected old-coordinate pivots. Each
eliminated coordinate is an affine polynomial in surviving coordinates;
all original affine equations vanish after this substitution, and projection
back onto surviving coordinates is the identity. Thus the quotient by the
branch's affine equations is exactly the polynomial ring in those surviving
coordinates, with no extra multiplicity.

The checker expands all 97 old-variable domain identities in every branch
as ordinary polynomials, before any field reduction:

```
(c + sum b_i*y_i)^3 - (c + sum b_i*y_i)
    = sum b_i*(y_i^3-y_i),  over F3.
```

Every eliminated domain is therefore already generated by the surviving
domains. Substituting the source moments and elementary cubics and then
reducing exponents modulo the explicitly retained y_i^3-y_i equations
preserves the ideal. The source sign-square equation remains unchanged.
Together these facts give an isomorphism of each complete branch quotient
with its reduced quotient. Offset and sign remain independent variables
at indices n-2 and n-1, so the count multiplier and divisor are both one.
